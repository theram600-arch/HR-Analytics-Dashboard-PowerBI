# HR-Analytics-Dashboard-PowerBI
Interactive HR Analytics Dashboard built in Power BI to analyze employee attrition, workforce trends, job satisfaction, salary insights, and department-wise performance using data visualization and DAX.

Learning Power BI felt difficult in the beginning, but with time, consistency, and practice, everything started becoming easier. 🚀

Excited to share my latest HR Analytics Dashboard built in Power BI! This project helped me improve my understanding of data visualization, dashboard design, and business insights.

📊 Dashboard Highlights:

✔ Total Employees & Active Employees Overview
✔ Attrition Count & Attrition Rate Analysis
✔ Department-wise Employee Distribution
✔ Salary Slab Attrition Insights
✔ Job Satisfaction Analysis
✔ Age Group Distribution
✔ Gender-wise Attrition Trends
✔ Experience-based Attrition Analysis

🛠 Tools & Skills Used:
Power BI
DAX
Data Modeling
Data Visualization
Business Intelligence

This project taught me how to transform raw data into meaningful insights that can help organizations make better HR decisions.
